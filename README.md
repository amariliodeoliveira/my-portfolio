Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Canonical site URL

The canonical URL is resolved centrally in `src/config/site.ts`. In production,
set `NEXT_PUBLIC_SITE_URL` to the preferred public origin, without a path:

```bash
NEXT_PUBLIC_SITE_URL=https://example.com
```

If it is not set, the app uses Vercel's production URL variables and finally
falls back to the project's stable `vercel.app` alias. A build regenerates all
metadata, JSON-LD, sitemap, and AEO files with the resolved origin.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
